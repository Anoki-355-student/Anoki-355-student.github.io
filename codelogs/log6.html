Code Log 6: Reference Quest

The CSS property I searched for is the font-family property.

The websites I have visited for more information would be W3schools CSS Reference, CssReference.io, CSS-Tricks, and Mozilla Developer Network (MDN) CSS Reference.

The information for each site listed seem more or less very similar, but some include more information on certain things than others. CssReference.io explains in detail the differences between font families or what makes them unique while most others do not. CSS Tricks has much more text and information in comparison to the amount of code provided in the reference page.

Features I believe code reference pages should offer include code examples and a thorough but not confusing explanation for the code's purpose.

I honestly prefer the MDN code reference page the most because I think that it has a good balance between explanation and code presented without being too overwhelming. I would not say it is necessarily bad, but the W3schools code reference page is a bit too brief for my taste and when compared to the other sites listed.
