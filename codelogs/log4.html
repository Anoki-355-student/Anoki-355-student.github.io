Code Log 4: Colors

What do these CSS properties do?

  • color
  • background-color
  • border-color

Color is represented through code as the color CSS datatype. Color may also be paired with other CSS properties to change the color of something like its background color with background-color or border color with border-color.

How does CSS accept color as a value? Provide examples of colors in these styles:

  • Named
  • Hexadecimal
  • RGB
  • System Color

There are many ways color may be accepted as a value. Named colors will, of course, be recognized by a colors name. The name of a color will be used as a keyword, and will be assigned a color based on it. Hexadecimals specify color through short codes rather than spelling out the name of a color. This allows for more specific choices of hue. RGB represents color based off on a scale or mixture of red, green, and blue. The system-color CSS datatype also uses keywords like named color would, but it's function is to color the different parts of a webpage.
