CSS Media Queries

How does a CSS media query work, and why is it useful?

A CSS media query works by responding to changes made to a layout, and following certain rules set by the developers. It is useful for creating a project that will operate as intended in more than one instance or set of conditions.

What "media features" are supported by media queries — such as "orientation" or "max-width" — and what do they do?

Media features that are supported by media queries may include width, orientation, hover, and pointer. Width is used as a measurable range and can be applied with a maximum or minimum prefix. The orientation media feature is meant to alter the layout in accordance to the landscape or portrait orientation of the project. The hover media feature ensures wether or not the user is able to hover over something. The pointer media feature is relative to how well a user may be able to target something with their pointer.
