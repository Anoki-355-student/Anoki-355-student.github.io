Code Log 1: HTML Semantic Tags

What is the difference between non-semantic and semantic tags in HTML?

From what I understand, the difference between a non-semantic tag and semantic tag in HTML would be that a non-semantic tag does not clearly describe the element's content. The semantic tag would, however, clearly desceribe the element's content.

What are two (or more) benefits of using semantic tags?

Two benefits of using semantic tags would include being able to read a websites code easier, as well as being able to write a websites code easier because it is a standard and consistent method.
